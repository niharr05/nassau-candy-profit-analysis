📁 FOLDER STRUCTURE:

├── requirements.txt               ← Libraries list
└── README.txt                     ← This file

══════════════════════════════════════════════════════════════
STEP 0 — FIRST TIME SETUP (only once)
══════════════════════════════════════════════════════════════

1. VS Code not installed? → https://code.visualstudio.com/
2. Python not installed? → https://www.python.org/downloads/
3. Keep the nassau_candy folder on the Desktop
4. Also keep Nassau_Candy_Distributor.csv in this folder
5. In VS Code → File → Open Folder → select nassau_candy
6. Open the terminal (Ctrl + `) and type:

   pip install -r requirements.txt

══════════════════════════════════════════════════════════════
STEP 1 — RUN ANALYSIS
══════════════════════════════════════════════════════════════

In the terminal, type:
   python analysis.py

You will get:
✅ Data info
✅ Product ranking table
✅ Division performance
✅ Pareto result (80/20 rule)
✅ ML Clustering result
✅ Charts — nassau_charts.png file will be saved

══════════════════════════════════════════════════════════════
STEP 2 — RUN DASHBOARD
══════════════════════════════════════════════════════════════

In the terminal, type:
   streamlit run app.py

The browser will open automatically: http://localhost:8501
There will be 4 tabs:
  📊 Product Profitability
  🏢 Division Performance
  💸 Cost vs Margin
  📉 Pareto Analysis
